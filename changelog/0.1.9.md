# ✨ feat: copy-triggered translation and consistent panel lifetime

## What's Changed

- Opt in to automatic translation after ⌘C in another app. Read only that copy for a bounded period, preserve the clipboard, and ignore idle clipboard changes and menu/right-click Copy. Accessibility access is required.
- Filter pure Chinese in automatic copy and selection queries while keeping mixed Chinese/English and detected Japanese eligible. New copy-filter settings default to Chinese; existing choices are preserved. Manual Clipboard Translation bypasses the filter.
- Keep pinned panels visible. Unpinned results hide after 10 idle seconds following completion, failure or stop; hovering, selection dragging and resizing renew the timer. Streaming results remain visible.
- Fix copy settings that appeared to revert because of preference observation keys. Preserve existing values and avoid triggering translation from the app's own copy actions.

## Download and install

- Requires **macOS 26+ and Apple Silicon (arm64)**.
- Download `easydict-lite-0.1.9-macos-arm64.zip`, extract `easydict-lite.app`, and place it in Applications alongside Easydict. Existing settings and Keychain credentials remain independent.
- Verify the ZIP with `SHA256SUMS.txt`.
- This prerelease is **ad-hoc signed, not Developer ID signed or notarized**. If macOS blocks opening it, follow [Apple's app-opening guidance](https://support.apple.com/en-us/102445).

## Validation and limitations

Eight existing tests, Release packaging, app/extracted-ZIP signatures, metadata, SDK linkage and localization parity were checked. The user confirmed that real ⌘C opens the result window; the final language-filter adjustment was checked with local source probes and review. Final real copy/filter and timed hover/pin scenarios, full Xcode validation and extended-use coverage remain incomplete.

Persistent Liquid Glass uses undocumented AppKit appearance queries; revalidate after macOS updates. Automatic contrast requires optional Screen Recording access and processes background pixels only in memory. Source-app selection depends on Accessibility support. Short words and shared Chinese/Japanese characters can remain ambiguous to language detection.
