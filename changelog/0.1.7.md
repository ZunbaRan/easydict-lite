# ✨ feat: a focused Liquid Glass translation app

## What's Changed

First public prerelease of **easydict-lite**, a streamlined fork of Easydict.

- Keep plain-text mouse selection and explicit Clipboard Translation for long passages. Translation preserves the clipboard; Copy result is an explicit action.
- Use an OpenAI-compatible Chat Completions API or the DeepSeek channel, with separate Keychain credentials and retained translation, word explanation, sentence analysis, and custom prompts.
- Keep the result panel's active Liquid Glass appearance when the pointer leaves. Automatic text contrast chooses dark or light text from local background brightness; Screen Recording access is optional and explicit.
- Preserve pinned position and size across new lookups. Pin remains usable while streaming; unpinning and finishing a drag keep the panel open. Pin colors update immediately, and the maximum-height slider displays changes in 1% steps.
- Normalize compatible API base URLs and support full Chat Completions endpoints.
- Explicitly disable thinking for translation and sentence analysis on DashScope and DeepSeek. Recognized single-word lookups can retain thinking; other compatible APIs need a non-thinking model for sentence translation.
- Remove OCR, screenshots, speech, offline dictionaries, other provider integrations, global shortcut settings, text replacement, telemetry, and the upstream updater.

## Download and install

- Requires **macOS 26+ and Apple Silicon (arm64)**. This release does not include an Intel or universal binary.
- Download `easydict-lite-0.1.7-macos-arm64.zip`, extract it, and move `easydict-lite.app` to Applications. It can coexist with Easydict; bundle ID, preferences, and Keychain entries are independent.
- `SHA256SUMS.txt` provides the ZIP checksum.
- The app is **ad-hoc signed, not Developer ID signed or notarized**. If macOS blocks the first launch, follow [Apple's guidance for opening downloaded apps](https://support.apple.com/en-us/102445). Source builds are also supported.

## Notes and validation

The release was built with the macOS 26.5 SDK. App and extracted-ZIP signatures, metadata, executable identity, and localization resources were checked; all eight retained cancellation and throttling tests passed. User feedback informed the API and panel fixes. Full Xcode validation, exhaustive UI/provider coverage, sleep/wake, and extended-use testing remain incomplete.

Persistent active glass uses two undocumented AppKit appearance queries isolated to the result panel, following EchoType's approach. Revalidate this behavior after macOS updates. System accessibility settings can alter the material. Automatic contrast processes background pixels only in local memory; images are not saved or sent to the translation API.

Selection requires text exposed through Accessibility; use Clipboard Translation when an application does not expose it. Input is sent in full up to 2 MiB; provider context limits still apply. Reasoning-only models cannot be forced into non-thinking mode by the app.
