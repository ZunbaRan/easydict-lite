# ✨ feat: a compact, resizable translation panel

## What's Changed

- Use a smaller header and move Copy result and Retry into icon-only toolbar actions. Remove the footer so translations have more room.
- Resize the panel's width and height by dragging its edges. Remember manual dimensions across lookups, reopening, and app restarts; streaming text does not resize the window.
- Show a blue checkmark for one second after a successful copy. Repeated clicks restart the confirmation timer.
- Reduce result text to 13 points and preserve long-text scrolling.
- Keep explicit Clipboard Translation, plain-text selection, OpenAI-compatible / DeepSeek APIs, prompts, pinned placement, and automatic background contrast.

## Download and install

- Requires **macOS 26+ and Apple Silicon (arm64)**.
- Download `easydict-lite-0.1.8-macos-arm64.zip`, extract `easydict-lite.app`, and place it in Applications alongside Easydict. Bundle ID, settings, and Keychain credentials remain independent.
- Verify the ZIP with `SHA256SUMS.txt`.
- This prerelease is **ad-hoc signed, not Developer ID signed or notarized**. If macOS blocks opening it, follow [Apple's app-opening guidance](https://support.apple.com/en-us/102445).

## Validation and limitations

Release packaging, app and extracted-ZIP signatures, metadata, SDK linkage, resource identity, and the eight existing tests were checked. The user accepted compact controls, resizing and persistence, streaming size stability, copy feedback, and the smaller text. Full Xcode validation, exhaustive app/provider coverage, and extended-use testing remain incomplete.

Persistent Liquid Glass uses undocumented AppKit appearance queries isolated to the result panel; revalidate after macOS updates. Automatic contrast requires optional Screen Recording access and processes background pixels only in memory. Selection still depends on Accessibility support in the source app; use Clipboard Translation for unsupported apps.
